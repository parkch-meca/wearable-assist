### 2.2 확립된 사실 — 슈트 설계 (연구 ②의 실질 기여)

**★★ ① 지배 인자는 토크 크기가 아니라 "부여 스팬과 부하 스팬의 정합"이다.**
같은 16.5 N·m 로 4조건 비교: 커플 T1↔골반(넓음) −27.2 % / 커플 L1↔골반(좁음) −6.7 % /
경로힘 L1→허벅지 **+0.1 %** / 경로힘 T8→허벅지 −2.8 %. → **스팬 효과가 방식 효과의 3배**.
부여 구간이 부하 구간을 덮지 못하면 힘·강성·모멘트암을 키워도 무효하거나 악화된다.

**★★ ② 허리 최적 배치 = T8 상단 + 천골 경유점 + 허벅지 최종 고정.**
- 상부 앵커 스윕 L1 → T12 → T8 → T4 에서 T8 이 실용적 상한 (T4 는 어깨 구동기와 충돌).
- 남던 LTpL(+24~28 %) 증가의 원인은 **하단 고정이 L5_S1 을 건너뛰는 것** — `LTpL_L5`는 L5_S1 만 교차하는데
  슈트 보조가 요구의 7.3 %(타 레벨 17~19 %)뿐. **천골 경유점 추가로 12.9 % → LTpL +24.7 → −0.6 % 해소.**
- 장골능 고정은 최악(LTpL +50.9 %). 상단·하단 **둘 다** 필요.
- 도달 최선: ES peak −22.6 / 활성도합 −19.8 / 근력합 −14.8 % = **이상적 분산 부여 대비 83 · 93 · 102 %**.

**★★ ③ 24 N·m 가정은 실측이 아니다 — (C) 병기 확정, 단 선형성 이탈.**
모멘트 암 가정 120 mm vs 재산출 79~89 mm → 현 하드웨어 조건은 **양측 합 15.7~17.8 N·m**(중앙 16.5).
5동작 수치는 유지하고 두 조건을 용량–반응 곡선의 두 점으로 병기. ⚠️ 실검증 결과 **곡선이 오목**
(16.5 N·m 가 24 N·m 효과의 83 %) → 비례 배분하면 과소평가. **병기 서술 방식 재검토 필요.**

**★★ ④ 어깨는 제외 확정 (L-08).** 전면 단일 경로는 굴곡될수록 상완 부착점이 앞으로 돌아
장력이 팔을 뒤로 당긴다(굴곡 보조 → 신전 저항). 캡 재설계 1회로도 50° 부호 반전 미해소, 유효 0~40°.
→ 게이트 기준 "슈트 r > 주동근 r" 은 **슈트가 주동근 바깥을 지나는 부위(허리·팔꿈치) 전용**으로 한정 확정.
(어깨는 삼각근이 상완골두를 감아 큰 r 을 갖고 체표 끈은 관절 가까이를 지나 기하 관계가 반대.)

**★★ ⑤ 팔꿈치 슈트는 견갑 앵커 연장안이 필수.** 이두근이 scapula→radius 이관절이라
상완–전완 기본안은 **삼각근 부담을 +6.9 % 늘린다**(팔꿈치 몫만 덜어 주니 어깨 몫이 삼각근으로 이동).
견갑까지 연장하면 −1.8 % 로 뒤집힌다. L1 고정이 L5_S1 을 건너뛴 것과 **동형 구조**.

**★★ ⑥ 부위 간 가산성 성립.** 운반 20 kg 에서 전체 ON = 허리 단독 + 팔꿈치 단독, **차이 최대 0.16 %**.
→ 다부위 설계에서 부위별 효과를 더해 예측 가능.

**★ ⑦ 피팅 자세가 결정적.** 팔 전면 경로는 굴곡 시 **짧아져** SMA 스트로크를 소진 → 이완각 어깨 80° / 팔꿈치 70°.
운반 팔꿈치각은 97.9° 고정이므로 중립(0°)에서 조여 입으면 장력이 내내 0. 작업 자세 피팅 필수
(대가: 팔 신전 시 100 N 상한 포화 = 뻣뻣해짐, 착용 시험 필요). 허리는 반대로 굴곡 시 신장 → 힘 유지·증가.

**★ ⑧ 직렬 탄성이 필수.** 100 N 상수 PathActuator 단독으론 관찰(무부하 기대 60 mm vs 실제 밴드 상승 10~15 mm)을
재현 못 한다. `x_SMA = (100 − T0 − k·ΔL)/(100/60 + k)`, k=2/5/8 N/mm 전부 캘리브레이션 PASS.
※ 사양표의 "병렬/직렬"은 **전기 결선**이다 — 역학적으로는 양쪽 다 병렬이라 50 N 소자 2장 = 100 N.

## 4. 반드시 지켜야 할 방법론 제약 (반복 실패로 확립)

1. **reserve 를 조이지 않으면 결론이 뒤바뀐다.** 척추 표준 reserve 가 ES 를 3배 과소평가했고, 어깨는 더 심하다
   (액추에이터 6 + reserve 6 **12개 전부 opt5** 필요 — 하나만 조이면 부하가 옆으로 이동).
2. **`InverseDynamicsTool` 사용 금지 (L-10)** — 이 모델에서 발산(L5_S1 4075, T8_T9 79290 N·m). 원인 미규명.
   → 요구 모멘트는 **검증된 SO 출력의 액추에이터 힘**에서 읽는다.
3. **ES peak 단독 판정 금지 (L-07)** — 재분배 상황에서 결정 근육 순위가 뒤바뀌어 정보를 잃는다
   (IL −25.5 / LTpT −26.6 % 개선인데 ES peak 는 −2.8 %로 보고됨). 다관절은 **3지표 병기**
   (peak · 활성도 합 · 근력 합). ⚠️ 5동작 주 지표는 소급 변경 금지.
4. **모멘트 암을 가정하면 같은 모델의 해당 근육 모멘트암과 대조**해 타당성 확인 (ES 최대 77 mm vs 가정 120 mm 사례).
5. **병렬 SO 실행 시 `OMP_NUM_THREADS=1` 필수.**
6. **조건 정합성 자동 감사** — 모델 해시·좌표 수·근육 수·reserve 설정·슈트 사양을 매번 대조
   (`audit_conditions.py`, `crosscheck_docs.py`, `paper_numbers.py` 단일 소스).
7. **시각 검증은 생성자와 분리된 독립 판정자가 수치 없이 그림만으로** 한다.
