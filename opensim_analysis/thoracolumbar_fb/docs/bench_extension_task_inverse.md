## 0. 무엇을 바꿔 돌렸나

**장력을 사슬 모델에서 풀지 않는다.** 한쪽 T ∈ {50, 100, 200, 300, 400, 600} N 을
자세 내내 일정하게 경로에 주고, 실측을 재현하는 T 를 되찾는다.
실제 하드웨어가 얼마를 내는지는 **인라인 로드셀 실측 대상**이다 (`measurement_requests.md` M-01).

| 항목 | 설정 |
|---|---|
| 동작 | 벤치 등 신전, 들기 구간 t = 3.0 ~ 5.8 s (85 프레임, 영상 ACTIVE 궤적) |
| 자세 | 변형 A(요추 10°) · B(요추 30°) 둘 다 — 승인대로 범위 보고 |
| 다리 구속 | (a) 좌표 고정 + 골반 residual 500/1000 · **고관절·무릎·발목 reserve opt 5** |
| 판정 | 활성도 ≤ 1 그리고 (고관절+척추) reserve ≤ 2 / 5 / 10 N·m 병기 |
| 근력 축소 | **Fmax × 0.95** — 34 kg 에서 척추 reserve 5.0 N·m (임계 5 기준 OFF 최대 = 34 kg) |

좌우 손 위치는 전 프레임에서 x·y 가 일치함을 확인하고 케틀벨 외력을 반씩 나눠 주었다
(과거 박스 좌팔 작용점 오류 재발 방지).

## 1. ★ G1 — 23 kg 에서 표면 ES −40 % 에 필요한 장력

표면 ES = L1~L3 높이대 후방 50 % (38 근육), 이전 보고와 같은 집합.
OFF 절대값: 들기 구간 평균 22.3 % · 최저점 25.6 % (변형 A 기준, B 도 0.1 %p 이내).

| T (한쪽 / 양측 합) | 들기 구간 A / B | 최저점 A / B | 척추 reserve |
|---|---:|---:|---:|
| 50 / 100 N | −8.5 / −8.7 % | −7.5 / −8.0 % | 5.2 / 4.0 |
| **100 / 200 N (사양)** | **−16.6 / −17.1 %** | **−14.6 / −15.5 %** | 5.1 / 4.0 |
| 200 / 400 N | −31.9 / −32.5 % | −28.1 / −29.1 % | 5.0 / 4.1 |
| 300 / 600 N | −46.1 / −46.5 % | −41.3 / −41.9 % | 4.9 / 4.3 |
| 400 / 800 N | −59.0 / −59.1 % | −54.2 / −54.5 % | 5.1 / 5.1 |
| 600 / 1200 N | −77.6 / −76.3 % | −76.1 / −73.6 % | 8.9 / 8.9 |

### 필요 장력 T_req

| 구간 | 변형 A | 변형 B | **범위** |
|---|---:|---:|---|
| 들기 구간 평균 | 257 N | 254 N | **254 ~ 257 N (한쪽)** · 507 ~ 514 N (양측 합) |
| 최저점 | 290 N | 285 N | **285 ~ 290 N (한쪽)** · 570 ~ 580 N (양측 합) |

- **자세 변형 A·B 차이는 3 N 이내** — 요추/골반 분담이 결론을 바꾸지 않는다.
- 반응은 T 에 거의 선형이다 (약 −0.155 %/N, 한쪽 기준).
- ⚠️ T = 600 N 에서는 척추 reserve 가 4.9 → 8.9 N·m 로 **뒤집혀 커진다** — 과보조다.

### 사양·모델과의 비교 (한쪽)

| | 장력 | 필요값 대비 |
|---|---:|---|
| 사슬 모델이 벤치 자세에서 낸 값 (가열) | 28 N | **1/9 ~ 1/10** |
| 사양 (좌우 각 100 N) | 100 N | **1/2.5 ~ 1/2.9** |

## 2. ■3 모멘트 암 점검 — 과소평가는 아니다

벤치 최저점, 한쪽 경로 기준 (mm).

| 변형 | L5–S1 | L4–L5 | L3–L4 | L1–L2 | T12–L1 | T8–T9 | 고관절 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A | 85.0 | 96.8 | 91.1 | 76.8 | 83.3 | 72.2 | −58.3 |
| B | 82.8 | 97.5 | 91.9 | 77.1 | 83.3 | 72.2 | −69.4 |

- 요추 전 레벨에서 **ES 최대 근속(77 mm)보다 크다** — 경로가 근육 바깥(체표)을 지난다는 게이트 통과.
- 고관절 모멘트 암은 음수 = **신전 보조** 방향 (부호 정상).
- 스냅샷에서 경로가 등 체표를 따라가는 것을 확인했다 (그림 패널 5).
- ⇒ **모멘트 암을 2배로 키울 여지는 없다.** 격차의 책임은 모멘트 암이 아니라 장력 쪽에 있다.

## 3. ★★ 전달 법칙 — 장력이 실제로 덜어 주는 양 (SO 에서 직접 합산)

L5–S1 을 교차하는 **모든 근육의 모멘트를 SO 출력에서 직접 합산**해, OFF 대비 감소량을 구했다.

| T (한쪽 / 양측) | 근육 L5–S1 모멘트 (A) | ΔM | reserve |
|---|---:|---:|---:|
| OFF | 281.5 N·m | — | 2.47 |
| 50 / 100 N | 273.1 | 8.4 | 2.40 |
| 100 / 200 N | 264.6 | **16.9** | 2.35 |
| 200 / 400 N | 247.7 | 33.8 | 2.26 |
| 300 / 600 N | 230.8 | 50.7 | 2.15 |
| 400 / 800 N | 213.9 | **67.6** | 2.07 |
| 600 / 1200 N | 180.1 | 101.5 | 1.94 |

**ΔM = 0.169 N·m per N (한쪽) = 2 · T · 84.5 mm** — 모멘트 암 실측(85.0 mm)과 정확히 일치한다.
변형 B 도 0.166 (83.2 mm) 으로 같다. **외력 생성·모멘트 암·SO 가 서로 검산됐다.**

## 4. G2 — 36 kg, 근력 축소 모델 (Fmax × 0.95)

### 4.1 ⚠️ reserve 판정은 이 과제에서 둔감하다 — 판정 기준이 작동하지 않았다

| 조건 | 고관절 reserve | 척추 reserve | 2 / 5 / 10 N·m 판정 |
|---|---:|---:|---|
| OFF | 0.11 | 8.52 | 불가 / 불가 / 가능 |
| T 100 N | 0.09 | 8.37 | 불가 / 불가 / 가능 |
| T 400 N | 0.14 | 8.07 | 불가 / 불가 / 가능 |
| T 600 N | 0.38 | 9.46 | 불가 / 불가 / 가능 |

**어떤 T 에서도 판정이 바뀌지 않는다.** 이유는 §3 이 보여 준다 —
T = 400 N 에서 근육 모멘트는 **−67.6 N·m** 나 줄었는데 reserve 는 8.52 → 8.07 로 거의 그대로다.

진단(프레임 0, 36 kg): 근육 모멘트 336.3 → 268.7 N·m (정확히 −67.6), 포화 근육 6 → 4 개,
reserve 5.32 → 4.92. **reserve 는 근력 부족분이 아니라 소수 근육의 포화·배분에서 남는
잔여항**이며, 슈트가 전체 부하를 덜어도 사라지지 않는다.

> **결론**: 승인받은 "활성도 ≤ 1 & reserve ≤ 임계" 기준은 이 과제에서 **T 를 구분하지 못한다.**
> 대신 §3 의 전달 법칙(근육 모멘트 감소 → 하중 환산)이 직접적이고 검산 가능한 척도다.

### 4.2 전달 법칙으로 답한 G2

OFF 최대 하중을 34 kg 으로 맞췄으므로 36 kg 을 들려면 **2 kg 분**만 메우면 된다.

**필요 T = 2 kg × 4.22 N·m/kg ÷ (2 × 0.085 m) = 50 N (한쪽) / 100 N (양측 합)**
→ 변형 A 50 N · 변형 B 51 N. **사양(한쪽 100 N) 안에 있다.**

⚠️ 단 이 값은 **근력 축소 스케일을 34 kg 에 맞춘 결과**다. 2 kg 간격은 설계된 것이므로
"사양 안에서 G2 가 만족된다"는 결론은 **스케일 선택에 종속**된다. 독립적인 정보는
전달 법칙(§3) 그 자체다.

## 5. 두 목표가 요구하는 장력이 5 배 다르다

| 목표 | 필요 T (한쪽) | 사양(100 N) 대비 |
|---|---:|---:|
| **G1** 23 kg 표면 ES −40 % | **254 ~ 290 N** | **2.5 ~ 2.9 배** |
| **G2** 34 → 36 kg 문턱 통과 | **50 ~ 51 N** | 0.5 배 (사양 안) |

같은 하드웨어로 두 관찰을 동시에 설명하려면 장력이 **50 N 과 290 N 사이 어딘가**여야 하는데,
그 폭이 6 배다. 즉 **두 실측은 서로 다른 강도의 요구**를 하고 있다.
EMG −40 % 쪽이 훨씬 엄격하며, 여기가 모델–실측 격차의 핵심이다.

- 사슬 모델이 벤치 자세에서 낸 장력은 **28 N (한쪽)** 으로 G1 필요값의 **1/9 ~ 1/10** 이다.
- 모멘트 암은 85 mm 로 이미 ES 최대 근속(77 mm)을 넘고, 2 배로 키울 여지가 없다(§2).
- ⇒ **남은 미지수는 장력뿐이다.** 실측(M-01)로 가른다.

## 6. 실측 판정 기준 (measurement_requests.md M-01 과 연동)

| 인라인 로드셀 실측 T (한쪽) | 해석 |
|---|---|
| **≥ 254 N** | 장력 가설 채택 — 힘 모델을 실측값으로 교체하면 G1·G2 모두 재현된다 |
| 127 ~ 254 N (G1 필요값의 50~100 %) | 장력만으로는 부족. 자세·기술 변화 등을 함께 봐야 한다 |
| **< 127 N** | 장력 가설 기각 — 남는 후보는 자세·기술 변화, 복압·공동수축 등 모델 밖 기전 |

※ G2 만 보면 50 N 으로도 설명되므로, **판정은 G1(EMG −40 %) 기준으로 한다.**
