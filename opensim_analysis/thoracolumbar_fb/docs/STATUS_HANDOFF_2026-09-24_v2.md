## 3. [2] 용량–반응 곡선 — ★ 이전 결론 정정

스툽 · 토크커플 고정 · 크기만 변경. 8 N·m 만 신규 SO(933 s), 나머지는 기존 실행 인용.
창 2.092~3.408 s · 모델 `ca12f321326e` 동일. 자료 `/data/suit_dose/dose.json`.

| 토크 | (a) ES peak | (b) 활성도 합 | (c) 근력 합 | 24 N·m 효과 대비 |
|---:|---:|---:|---:|---|
| 0 (절대값) | 64.62 % | 1488.5 %·s | 2940 N·s | — |
| 8 | −13.2 % | −10.3 % | −7.0 % | 40 / 33 / 34 % |
| 16.5 | −27.2 % | −21.3 % | −14.5 % | 83 / 69 / 69 % |
| 24 | −32.8 % | −31.0 % | −20.9 % | 100 % |

### ★★ "용량–반응이 오목하다"(2026-08-16)는 지표 아티팩트였다

- **총 부하 지표 (b)(c) 는 선형** — 직선 대비 편차 **0.1 %p 이내**. 부하 자체는 토크에 비례한다.
- 오목한 것은 **ES peak 하나**뿐 (편차 최대 4.7 %p).
- 원인 규명 — **peak 결정 근육이 바뀐다**: `IL_R10_r`(0·8·16.5 N·m) → `LTpL_L5_r`(24 N·m).
  max 연산이 다른 근육을 집는 순간 총 부하와 어긋난다 (L-07 과 동형).

**→ L-01 서술 확정**: 24 N·m 와 15.7~17.8 N·m 를 **4점 곡선 위의 두 지점**으로 제시한다.
비례 배분 금지는 **주 지표(ES peak)에 한정**되며, 총 부하 지표로는 비례가 정확하다.

⚠️ 이 곡선은 **분산 부여(토크커플) 축**이다. 같은 16.5 N·m 를 현 하드웨어 기하(경로힘 L1→허벅지)로
주면 (a) +0.1 / (b) −9.8 / (c) −3.4 % 로 곡선 밖이다 — **여전히 방식이 크기를 지배**한다.

## 4. [3] 들기 20 kg 다부위 — 운반의 두 결론 모두 재현

운반과 같은 조건·같은 분석 코드, OFF 부터 재산출. 창 2.333~5.433 s (94프레임), OFF ES peak 94.66 %.
SO 5조건 각 ~27 분 (병렬, `OMP_NUM_THREADS=1`). 자료 `/data/suit_box/metrics.json`.

| 조건 | (a) ES peak | (b) 활성도 합 | (c) 근력 합 | 삼각근 | 팔꿈치 굴근 |
|---|---:|---:|---:|---:|---:|
| 허리만 (조건 B) | −17.9 % | **−15.5 %** | −12.7 % | −0.8 % | +0.0 % |
| 팔꿈치만 (기본안) | +0.0 % | +0.0 % | +0.0 % | **+11.2 %** | −15.2 % |
| 팔꿈치만 (연장안) | −0.0 % | +0.0 % | +0.0 % | **−1.5 %** | −11.4 % |
| 전체 ON | −17.9 % | −15.5 % | −12.7 % | −2.2 % | −11.4 % |

### 판정

| 결론 | 운반 | 들기 | 판정 |
|---|---:|---:|---|
| (a) 가산성 (차이/합) | ≤0.16 % | **≤0.16 %** (활성도 합 0.04 %) | **재현** |
| (b) 스팬 불일치 — 기본안 삼각근 | +6.9 % | **+11.2 %** | **재현 (1.6배 크다)** |
| (b) 연장안에서 해소 | −1.8 % | **−1.5 %** | **재현** |

들기는 어깨 굴곡이 있어(창내 elv_angle 26.6°, 최대 62.9°) 기본안의 어깨 페널티가 더 크다.

### ⚠️ 새로 드러난 대가 — 연장안은 어깨가 굽으면 팔꿈치 보조가 줄어든다

| 설계 | 창내 경로장 | 장력 평균 | 팔꿈치 굴근 |
|---|---|---:|---:|
| 기본안 (2점) | 199~256 mm | 44.3 N | −15.2 % |
| 연장안 (3점) | 293~378 mm | 32.9 N | −11.4 % |

견갑 앵커는 어깨 굴곡에도 경로가 짧아져 스트로크를 더 쓴다. 손실 크기는 어깨 굴곡 범위에 비례한다
(운반은 어깨각 5° 고정이라 손실 거의 없음: −17.7 → −17.6 %).
그래도 삼각근 +11.2 %p 페널티를 없애는 편이 이득이므로 **연장안 유지**.

### ⭐ 피팅 자세 — 들기는 중립 기립으로 충분 (L-11 신규)

창내 팔꿈치각 **32.0°** (20~62°) 로 이완각 70° 이내 → 해부학적 중립에서 착용해도 장력이 산다.
운반은 97.9° 로 초과해 작업 자세 피팅이 불가피했다. **두 동작의 팔 슈트 착용 조건이 다르므로
팔꿈치 효과 절대값은 직접 비교하지 않는다.** 실사용에서는 작업별 BOA 재조정이 필요하다.
