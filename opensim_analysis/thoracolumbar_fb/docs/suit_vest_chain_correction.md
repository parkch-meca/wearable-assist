## 1. 왜 고치는가

실측과 시뮬레이션이 어긋난다.

| 실측 (사용자 보고) | 기존 시뮬레이션 |
|---|---|
| 36~40 kg 케틀벨을 허리힘만으론 못 들던 사람이 슈트 착용 후 반복해서 들어올림 | 현 하드웨어 기하 조건 효과 **+0.1 %** (ES peak) |
| 반복 들기에서 척추기립근 EMG **40 % 이상 감소** | 총 부하 지표로도 −9.8 % |
| 수동형(미가열)은 효과 미미 → 효과의 주성분은 SMA 능동 수축 | 모델은 미가열에서도 100 N 을 낸다 (§5) |

**시뮬레이션 쪽 오류로 판정한다.** 원인 두 가지를 이번에 확인했다 — (a) 힘 작용점, (b) 힘 상한.

## 2. 사진 판독 — 세 구동기의 힘 사슬 (끝점까지)

출처: `docs/refs/복합관절 근력보조 슈트 구성.pdf` p.1~3 (렌더 `docs/refs/pdf_pages/`),
sartexo 제품 사진 3장 (`/data/suit_photos/`).

### 2.1 ★ 허리 — 제품은 조끼다

```
어깨끈(견봉 위 접촉)  →  조끼 등판(흉추 체표)  →  근육옷감 구동기(하부 등)
                     →  BOA  →  천골·둔부  →  허벅지 밴드
```

- `waist-suit-parts-labeled` 후면 사진: **Fabric muscle 은 조끼 등판에 봉제**되어 있고,
  그 아래로 BOA → Thigh band 로 이어진다. 근육옷감 윗끝이 몸(뼈)에 고정된 곳은 **없다**.
- 조끼가 아래로 끌려 내려가지 않게 잡아 주는 것은 **어깨끈**(가방끈 형태, PDF 명칭 "어깨 지지 밴드").
- 허리 지지 밴드(복대)는 등판을 몸에 **눌러 붙이는** 역할이다. 사슬을 끊지 않는다.
- 직렬 사슬이므로 **장력은 전 구간 동일**하고, 몸에 힘이 걸리는 끝점은 **어깨와 허벅지**다.

> ⚠️ 기존 모델은 구동부(근육옷감)가 **놓인 위치**(L1 높이)를 힘의 **작용점**으로 썼다.
> 구동기 위치와 힘 작용점을 혼동한 것이다.

### 2.2 팔꿈치 — 기존 "연장안"이 실제 제품

```
조끼 어깨 요크(견봉)  →  상완 전면  →  BOA(원위 상완)  →  전완 커프
```

PDF p.2 좌측(전면)에서 상완 전면의 구동기가, 우측(후면)에서 **같은 조각이 견갑 위로
넘어가는 것**이 보인다. 상완–전완만 걸치는 기본안은 실제 제품이 아니다.

### 2.3 ★ 어깨 — 후면 대각 경로 (기존 전면 경로는 오독)

```
상부 등(흉추 3 부근, 견갑 내측)  →  견봉 위 경유  →  상완 외측(삼각근 조면 높이) BOA
```

- PDF p.1 후면 뷰: "근육옷감 구동기(어깨 관절 보조용)"가 **등 위쪽에서 대각선으로
  어깨를 넘어간다**.
- `crop_C_side`: 어깨 구동기 길이 조절 BOA 가 **상완 외측**에 있고, 녹색 와이어가
  견봉 위를 넘어 내려온다.
- 기존 모델의 **전면 단일 경로는 사진과 맞지 않는다**.

## 3. 재구성한 모델 경로 (중립 기립 실측)

경유점은 눈대중이 아니라 **체표면 실측**(근육 외피 + 피하 10 mm + 의복 5 mm)으로 잡았다.
견봉은 삼각근·승모근 기시점 중 최상단, 삼각근 조면은 삼각근 정지점 평균으로 정의했다.

| 부위 | 경로점 | 중립 길이 |
|---|---|---:|
| 허리 | 견봉(견갑) → 흉추2·4·6·8·10·12 → 요추1~5 체표 → 천골 → 허벅지 | 885.2 mm |
| 어깨 | 흉추3 체표 → 견봉 위 → 상완 외측 | 359.5 mm |
| 팔꿈치 | 견봉(조끼 요크) → 상완 전면 → 전완 커프 | 400.0 mm |

### 3.1 ★ 바뀌는 것은 모멘트 암이 아니라 **스팬**이다

| 좌표 | 조건 A (L1→허벅지, 기존 "현 하드웨어") | 조건 B (T8→천골→허벅지) | **조끼 사슬 (신규)** |
|---|---:|---:|---:|
| T4_T5 | 0.0 | 0.0 | **81.2** |
| T8_T9 | 0.0 | 72.2 | 72.2 |
| T12_L1 | 0.0 | 83.3 | 83.3 |
| L1_L2 | 76.5 | 76.5 | 76.5 |
| L3_L4 | 90.3 | 90.3 | 90.3 |
| L5_S1 | 86.8 | 85.9 | 85.9 |

**요추 모멘트 암은 세 조건이 같다.** 조건 A 가 효과 0 이었던 이유는 힘이 작아서도,
모멘트 암이 짧아서도 아니라 **흉추 전 레벨의 모멘트 암이 0** 이었기 때문이다
(= 부여 스팬이 부하 스팬을 못 덮는다, §10 의 결론과 정확히 같은 구조).
조끼 사슬은 어깨끈까지 올라가므로 흉추를 포함한 **전 레벨**에 보조가 간다.

### 3.2 어깨 — 부호 반전이 사라졌다

| elv_angle (°) | 0 | 20 | 40 | 50 | 60 | 80 | 90 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 슈트 모멘트 암 (mm) | 9.0 | 20.7 | 31.4 | 36.3 | 40.8 | 48.0 | **50.6** |
| 삼각근 최대 근속 (mm) | 47.9 | 50.5 | 46.8 | 41.3 | 32.6 | 32.1 | 34.4 |

후면 대각 + 견봉 경유 경로는 **0~90° 전 구간에서 부호가 유지**되고 굴곡할수록 커진다.
기존 전면 경로가 50° 에서 반전하던 것과 정반대다. 60° 이상에서는 슈트 모멘트 암이
삼각근 근속을 넘는다. → **L-08(어깨 제외)은 재판정 대상**이다.

⚠️ 단 경로장이 359.5 → 308.3 mm 로 **51 mm 짧아진다**(스트로크 60~80 mm 이내) —
중립 피팅이면 고각도에서 장력이 줄어든다. 피팅 자세 문제는 L-11 그대로 적용된다.

### 3.3 팔꿈치

모멘트 암 33.3 mm(0°) → **64.6 mm(75°)** → 31.1 mm(120°). 전 구간 양(+)이며 주동근(BRA 30.9 mm)보다 크다.
경로장은 400 → 287.5 mm (−112 mm) 로 스트로크를 넘는다 → 작업 자세 피팅 필요(L-11).

## 4. 확인만 한 항목 — 메쉬 리미터 / 100 N 상한 처리 (■2-2)

현재 코드 `scripts/viz_knee_fix/suit_model.py::solve()`:

```
x_SMA = (100 − T0 − k·ΔL) / (100/60 + k),   x_SMA ≥ 0   ← 메쉬 리미터
F     = 100·(1 − x_SMA/스트로크)                         ← 가열 수축 분기
x_SMA = 0 이면  F = min(T0 + k·ΔL, 100)                  ← 수동(신장) 분기
```

- **두 분기 모두 100 N 에서 잘린다.** 스툽에서 허리 경로는 ΔL ≈ +150 mm 이므로
  수동 분기의 k·ΔL = 750 N 이 100 N 으로 포화한다.
- 즉 **현재 모델은 가열/미가열을 구분하지 못한다.** 실측에서 수동형 효과가 미미했던 것과
  모순이며, 동시에 구속 가열 시 정격을 넘는 회복응력도 표현하지 못한다.
- 기존 운반·들기 해석에서 허리 장력은 79.2~100 N (평균 97.4 N) 으로 **거의 항상 상한**이었다.

> 사용자 지시대로 이 항목은 **주 가설로 다루지 않고 보고만** 한다.
> ■2 에서는 구속 가열 힘을 100 / 150 / 200 / 250 N 으로 스윕한다.

## 5. 승인 요청 — 여기서 멈춘다

지시(`■1 승인 후 ■2~■5 진행`)에 따라 SO 는 실행하지 않았다. 아래 확인 후 진행한다.

1. **허리 사슬 상단을 견봉(어깨끈)으로 두는 것** — 복대가 등판을 붙잡아 일부 하중을
   골반으로 흘릴 가능성은 있으나, 사진상 근육옷감이 복대가 아니라 **등판**에 봉제돼 있어
   어깨끈을 끝점으로 잡았다. 실착 감각(어깨에 눌리는 느낌 유무)으로 교차 확인 가능.
2. **어깨 경로를 후면 대각 + 견봉 경유로 재구성** — L-08 재판정을 포함한다.
3. **경유점 좌우 간격 Z_LAT = 40 mm** (기존 허리 경로와 동일 값 유지). 근육옷감 폭이
   110 mm 이므로 중심간 60~80 mm 일 수 있다 → 민감도 항목으로 둘지 확인 필요.
